**Badge** — small pill for a status label or count. Status tones (`success`/`warning`/`danger`) mean status, never decoration.

```jsx
<Badge tone="primary">New</Badge>
<Badge tone="success" dot>Active</Badge>
<Badge tone="neutral">Draft</Badge>
```

Props: `tone` (`neutral`/`primary`/`success`/`warning`/`danger`), `dot`.
